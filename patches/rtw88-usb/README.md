# RTW88 USB patches

Store one patch per logical change, numbered in application order.

Suggested naming:
- `0001-linuxkpi-usb-....patch`
- `0002-rtw88-usb-....patch`

Every patch should include its target FreeBSD revision, rationale, affected files, how to apply/revert it, and build/test results. The current reserved-page synchronous-write experiment exists in the local source tree but has not yet been imported here; do not recreate it from a summary.
